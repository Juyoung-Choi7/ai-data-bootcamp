# Olist 프로젝트 1

## 프로젝트 개요
배송 지연이 고객 리뷰에 미치는 영향을 분석하는 프로젝트입니다.

## 핵심 질문
- 배송 지연 여부에 따라 리뷰 점수가 유의하게 달라지는가?
- 다른 요인을 통제해도 관계가 유지되는가?
- 어떤 카테고리와 배송 단계에서 위험이 높은가?

## 분석 방법
- Mann-Whitney U 검정
- Cliff's delta
- OLS 회귀분석
- 순서형 로지스틱 회귀
- 배송 단계별 소요시간 분석
- 카테고리별 위험지수 산출

## 결과 요약
배송 지연이 고객 만족도에 유의미한 영향을 줄 수 있으며, 지연이 집중되는 단계와 카테고리를 파악해 운영 개선 방향을 제시할 수 있습니다.
