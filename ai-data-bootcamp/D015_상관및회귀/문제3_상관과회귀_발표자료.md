# 문제 3 · 상관과 회귀, 하나의 식으로 연결하기

**날개 길이(flipper_length_mm) → 몸무게(body_mass_g)**

> 🎤 발표 오프닝 (선택): "이번 문제는 앞서 구한 상관계수가 회귀분석의 기울기·결정계수와
> 실제로 어떻게 연결되는지, 숫자로 직접 검증해보는 문제였습니다."

---

## 1. 문제 상황

- 상관계수 r은 "관계가 있다 / 강하다"만 알려줄 뿐, 실제 변화량은 알려주지 않는다.
- 회귀분석(선형회귀)은 `y = a + bx` 형태의 식으로 관계를 구체적인 숫자로 표현한다.
- **핵심 포인트**: 단순회귀에서는 상관계수 r과 회귀의 기울기·결정계수(R²)가 수학적으로 같은 뿌리에서 나온다.

---

## 2. Q1·Q2 — 회귀모형 적합 & 결과표 확인

## 3. Q3 — 회귀식 완성

```
몸무게(g) = -5780.8314 + 49.6856 × 날개길이(mm)
```

- **기울기(b) = 49.6856** → 날개 길이가 1mm 길어질 때, 몸무게는 평균적으로 약 49.69g 증가
- **절편(a) = -5780.8314** → "날개 길이 0mm인 펭귄의 몸무게"로 해석하면 안 됨
  - 실제 데이터 범위(약 170~230mm)를 한참 벗어난 **외삽(extrapolation)** 이라 의미 없음

## 5. Q5 — 상관과 회귀를 잇는 두 관계식 검증

| 관계식 | 계산값 | 실제값 | 일치 |
|---|---|---|---|
| 기울기 = r × (std_y / std_x) | r=0.8712 대입 시 ≈ 49.69 | model 기울기 49.6856 | ✅ |
| R² = r² | 0.8712² = 0.7590 | model.rsquared = 0.759 | ✅ |

> 💡 발표 포인트: 두 값이 오차 범위(소수점 이하) 내에서 정확히 일치한다는 것은,
> 회귀분석의 기울기·R²가 상관계수 r로부터 **수학적으로 유도되는** 값임을 뜻함
> (별개의 두 분석이 우연히 비슷한 게 아니라, 원래 하나의 식에서 파생된 것)

→ **상관계수 r과 회귀의 기울기·R²는 서로 다른 개념이 아니라, 단순회귀에서는 수학적으로 하나로 이어져 있다.**

## 6. 정리 — 오늘 배운 것

### 📌 절편(a)의 함정
- 절편이 음수라고 해서 "실제 의미 있는 예측값"으로 해석하면 안 됨
- 회귀식은 **데이터가 존재하는 범위 안에서만** 신뢰할 수 있음

### 📌 x, y를 바꾸면?
- **기울기(b)** → 달라짐 (공식의 분자·분모가 뒤바뀜)
- **결정계수(R²)** → 동일함 (r은 순서를 바꿔도 값이 같으므로, R²=r²도 동일)

### 📌 상관 vs 회귀, 뭐가 더 알려주는가?
| | 상관계수 r | 회귀 기울기 b |
|---|---|---|
| 단위 | 없음 (-1~1) | 실제 단위 (예: g/mm) |
| 알려주는 것 | 관계의 방향과 강도 | 구체적인 변화량 예측 |

→ 상관은 "관계가 있다"는 사실만, 회귀는 "얼마나 변하는지"까지 알려주는 실전 도구

## 🙋 예상 질문 대비 메모

- **Q. 절편이 음수인데 이상하지 않나요?**
  → 절편은 x=0일 때의 예측값을 수학적으로 고정하는 값일 뿐, 데이터 범위(170~230mm) 밖이라 실제 의미는 없음 (외삽 금지)

- **Q. x와 y를 반대로 두면 결과가 똑같나요?**
  → 기울기는 달라지지만, R²는 r²이므로 동일함 (r 자체가 순서에 영향받지 않기 때문)

- **Q. 회귀가 상관보다 나은 점이 정확히 뭔가요?**
  → 상관은 "관계가 있다/강하다"만 말해주지만, 회귀는 실제 단위(g/mm)로 예측치까지 계산해줌

- **Q. 문제 2에서 정규성이 깨져서 피어슨 대신 스피어만이 낫다고 했는데, 회귀는 왜 피어슨 r과 연결되나요?**
  → "정규성"이 붙는 대상이 서로 다름
  - 피어슨 r의 정규성 가정: **x, y 각 변수 자체**의 분포 (문제 2에서 기각됨)
  - 회귀분석(OLS)이 필요로 하는 정규성: **잔차(residual)**의 분포 (문제 5에서 별도 진단 → 문제없음 확인)
  - r ↔ 회귀 기울기·R²의 관계식(기울기=r×std비율, R²=r²)은 가정과 무관한 **순수 수학 공식**이라 항상 성립함
  - 즉 서로 다른 층위의 이야기라 모순이 아니며, 표본이 큼(n=342)+잔차 진단 통과 덕분에 회귀분석을 그대로 신뢰할 수 있었음
