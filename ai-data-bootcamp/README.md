## Data Analysis Projects

### 1) 배송 지연이 고객 리뷰에 미치는 영향 분석

**Dataset:** Olist Brazilian E-Commerce Dataset

배송 지연이 고객 리뷰 점수에 미치는 영향을 통계적으로 검증했습니다.

- Mann-Whitney U 검정
- Cliff's delta
- OLS 회귀분석
- 순서형 로지스틱 회귀
- 배송 단계별 소요시간 분석
- 카테고리별 위험지수 산출

배송 지연 여부에 따른 리뷰 점수 차이를 확인하고, 다른 요인을 통제한 이후에도 그 관계가 유지되는지 검증했습니다.

분석 결과를 바탕으로 배송 지연이 주로 발생하는 구간과 카테고리별 위험도를 파악하고, 운영 및 고객경험 측면의 개선 방향을 제안했습니다.

- 관련 자료: [D025olist프로젝트1](D025olist프로젝트1/)
- 최종 노트북: [olist_delivery_review_analysis_final.ipynb](D025olist프로젝트1/notebook/olist_delivery_review_analysis_final.ipynb)

### 2) SQL 기반 상품 추천 로직 설계

**Dataset:** Amazon 판매 데이터

상품 데이터를 SQL로 정제하고, 리뷰 수와 평점을 함께 고려한 상품 평가 로직을 설계했습니다.

- 결측치 및 중복 데이터 정제
- SQL을 활용한 데이터 분석
- 리뷰 수와 평점을 결합한 점수 설계
- IMDB 가중 평점 공식을 응용한 추천 기준 설계
- 5가지 추천 로직 비교

이 프로젝트는 단순한 인기순 정렬이 아니라, 신뢰성 있는 평가를 반영한 추천 로직을 설계하는 데 초점을 두었습니다.

### 3) A/B Test 데이터 분석

A/B 테스트 데이터를 활용해 광고 인지도 상승의 통계적 유의성과 ROI 민감도를 분석했습니다.

- A/B 테스트 결과 분석
- 통계적 유의성 검증
- ROI 분석
- 결과의 민감도 검토

실험 결과를 기반으로 광고 성과를 정량적으로 해석하고, 비즈니스 의사결정에 연결할 수 있는 방향을 제시했습니다.
