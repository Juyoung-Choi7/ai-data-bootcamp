# 데이터 분석 보고서

*1. 분석개요*

- 대상: 모두마켓 주문 1,500건 (2025-01 ~ 2025-05), 고객·상품 정보 병합

- 방법: 3개 테이블 키 검증 후 m:1 병합 → 월별 KPI 집계 → 교차표·점유율 분석


*2. 핵심 발견*

- 매출이 가장 높았던 달은 2025-03월이었으며, 전월 대비 증감률은 매출증감률(%) 열에서 확인.

- 카테고리 중 패션, 지역 중 인천 의 매출 기여가 가장 컸음.

- 전체 객단가는 약 60,637원.


*3. 데이터 신뢰성*

- 병합 전 키 검증: 중복 0건, 미매칭 0건 → 행 폭증·조용한 결측 없음.

- validate="m:1" 통과 → 관계 가정(주문:상품 = m:1) 유효.


*4. 제언*

- 패션 카테고리는 총매출(38,318,000원), 주문건수(512건), 객단가(74,840원),
  구매고객수(183명) 등 모든 지표에서 1위를 기록함.
  → **근거**: [카테고리별 KPI 요약표]에서 category별 총매출·주문건수·객단가·구매고객수 집계 결과.
  → 패션 카테고리 내 상위 상품 라인업을 확대하고, 타 카테고리(뷰티·식품) 대비
    낮은 객단가(뷰티 52,010원, 식품 56,291원) 상품과의 번들 판매로 교차 매출 증대 검토.

- 인천 지역은 총매출 27,577,000원으로 4개 지역 중 1위를 기록함.
  → **근거**: [지역 x 회원등급 매출 교차표]에서 region별 합계 매출 비교
    (경기 21,145,000 / 서울 23,480,000 / 부산 18,754,000 / 인천 27,577,000).
  → 인천 지역 물류·마케팅 자원 우선 배정 검토.

- 다만 인천은 basic(17,372,000원)·premium(9,675,000원) 매출은 강세인 반면,
  vip 매출은 530,000원으로 전 지역 중 가장 낮음(서울 vip 2,322,000원과 대비).
  → **근거**: [지역 x 회원등급 매출 교차표]에서 인천 행의 등급별 매출 비교.
  → 인천 지역은 basic·premium 고객층이 두터운 반면 vip 전환이 저조하므로,
    인천 지역 대상 vip 등급 업그레이드 프로모션(등급 혜택 안내, 리텐션 캠페인)을
    별도로 설계할 필요가 있음.

- 전체 평균 객단가는 60,637원이며, 카테고리별 편차가 큼(패션 74,840원 vs
  가전 50,874원). 카테고리 특성에 맞는 가격대별 세그먼트 전략이 필요함.
  → **근거**: [카테고리별 KPI 요약표]의 카테고리별 객단가 비교.
