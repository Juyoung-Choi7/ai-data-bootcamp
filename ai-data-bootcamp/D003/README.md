-amount 이상치 145건
 -500만원 결측치 고가 물건 1개 혹은 입력오류 가능성 
 -확인결과 가격과 개수와의 불일치로 입력오류로 판단됨

 -확인결과 동일제품 동일개수 구매 이상치 아님
-return_amont 이상치 122건
 -상한과 하한 모두 0으로 iqr로 확인하기 적합하지 않음
 -확인결과 반품 비율은 약 8%로 나올 수 있는 수치이고 amount의 값을 초과하지 않으므로 결측치는 없다고 판단

- 주요 컬럼: order_id, customer_age, category, channel, price, quantity, amount, return_amount

## 2. 진단 결과
