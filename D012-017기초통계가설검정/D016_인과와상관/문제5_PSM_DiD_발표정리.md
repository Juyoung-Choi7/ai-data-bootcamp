# 문제 5. 실험할 수 없을 때 — PSM과 DiD로 인과효과 추정하기

## 0. 왜 이 문제가 필요한가

문제 4에서 우리는 확인했습니다.

- 무작위 배정(RCT)만 되면 인과효과는 **단순 평균 차이**로 구해집니다.
- 문제는 **대부분의 현실에서 무작위 배정이 불가능**하다는 것입니다.

그래서 관찰 데이터만 놓고 인과효과에 다가가는 방법들이 필요합니다. 이번 문제에서는 대표적인 두 가지를 다룹니다.

| 방법 | 핵심 아이디어 | 필요한 데이터 |
|---|---|---|
| ① 경향점수 매칭 (PSM) | 처치를 받을 '경향'이 비슷한 사람끼리 짝지어 '통계적 쌍둥이' 집단을 만든다 | 한 시점의 단면 데이터 |
| ② 이중차분법 (DiD) | 시간축을 도입해, 통제군의 변화를 '정책이 없었다면 일어났을 변화'로 삼고 실험군의 변화에서 빼낸다 | 여러 시점의 패널 데이터 |

두 방법 모두 **가정 위에 서 있습니다.** 그래서 이 문제의 진짜 목표는 추정값 하나를 구하는 것이 아니라, **그 가정을 검증하는 절차까지 해보는 것**입니다.

---

## 1. 경향점수 매칭 (PSM, Propensity Score Matching)

### 1-1. 상황 설정

같은 학생 2,000명에게 '새 온라인 강의'를 배정하는 두 가지 방식을 비교합니다.

- **관찰연구(df_obs)**: 성적이 좋고 열심인 학생이 스스로 신청 → **선택 편향** 발생
- 강의의 참 효과(우리가 되찾아야 하는 값): **+5.0점**

```
관찰연구 데이터: 2,000행
  수강생 751명 / 비수강생 1,249명
  단순 평균 비교: +11.34점   ← 참 효과(5.0점)보다 훨씬 부풀려짐
```

수강생 쪽의 사전점수(pre_score), 학습시간(study_hours)이 비수강생보다 눈에 띄게 높습니다. **"성적 좋고 열심인 학생이 스스로 신청했다"**는 선택 편향이 숫자로 드러난 것입니다.

### 1-2. PSM의 3단계

**Step 1. 경향점수 추정**
로지스틱 회귀로 각 학생이 강의를 신청할 확률(=경향점수)을 추정합니다.

```
설명변수: pre_score, study_hours   →   반응변수: course(수강 여부)
```

수강생·비수강생의 경향점수 분포를 히스토그램으로 겹쳐보면, 두 집단이 겹치는 구간이 있어야 짝을 찾을 수 있습니다.

**Step 2. 1:1 짝짓기**
수강생(실험군) 한 명마다, 경향점수가 가장 가까운 비수강생(대조군) 1명을 찾아 짝짓습니다. 짝지어진 두 집단의 `final_score` 평균 차이가 **ATT(처치집단에 대한 평균 처치효과)**입니다.

```
① 단순 평균 비교:  +11.34점
② PSM 이후 ATT:    +5.02점   ← 참 효과에 훨씬 가까워짐
③ 참 효과:         +5.0점
```

**Step 3. 짝짓기 검증 — 공변량 균형(Covariate Balance)**
짝짓기는 **"잘 됐다고 가정하면 안 되고, 확인해야 합니다."** pre_score, study_hours에 대해 두 집단의 평균 차이를 짝짓기 전/후로 비교합니다.

```
              짝짓기 전    짝짓기 후
pre_score      7.687        0.074
study_hours    1.382        0.025
```

짝짓기 후 차이가 0에 가까워졌으므로 성공입니다.

### 1-3. PSM의 한계 — RCT와 비교

> **PSM은 경향점수 모형에 넣은 변수만 균형을 맞춥니다.**

문제 4의 RCT는 무작위 배정 덕분에 **관측했든 안 했든 모든 교란요인**이 저절로 균형을 이룹니다. 반면 PSM은 우리가 모형에 직접 넣은 변수(pre_score, study_hours)에 대해서만 균형을 맞춰줍니다.

만약 우리가 모르는 교란요인(예: 학생의 타고난 이해력)이 존재한다면, PSM은 이를 통제하지 못하므로 **Q2의 ATT를 엄밀한 인과효과라 부르기는 어렵고**, "우리가 측정한 교란요인을 통제했을 때의 추정치"라는 제한적 해석만 가능합니다.

## 2. 이중차분법 (DiD, Difference-in-Differences)

### 2-1. 상황 설정

서울(실험군)과 부산(통제군)의 1인당 월 데이터 사용량을 봅니다. 무료 공공 와이파이 정책이 **2024년 서울에만** 시행되었고, 정책의 참 효과는 **+4.0GB**입니다.

```
패널 데이터: 3,600행 (도시 2 × 300명 × 6년, 2020~2025)
```

### 2-2. DiD를 계산하기 *전에* — 평행추세 가정 확인

DiD는 계산 전에 반드시 확인해야 할 가정이 있습니다.

> **평행추세 가정(Parallel Trends Assumption)**: 정책이 없었다면, 두 집단의 격차는 시간이 지나도 일정하게 유지되었을 것이다.

정책 시행 이전(2020~2023) 구간만 잘라서 두 도시의 격차를 확인합니다.

```
연도    부산     서울    격차(서울-부산)
2020   10.16   14.69      4.53
2021   11.54   16.27      4.73
2022   13.08   17.71      4.63
2023   14.60   19.22      4.63
```

격차가 4.5~4.7GB 사이에서 거의 일정하게 유지 → **평행추세 가정을 믿을 만합니다.**

> 만약 이전부터 격차가 벌어지고 있었다면, 이후 계산할 DiD 계수는 정책의 순수한 효과가 아니라 **원래 있었던 추세가 섞인 값**이므로 그대로 정책 효과라 해석해서는 안 됩니다.

### 2-3. 2×2 DiD 회귀

정책 직전 해(2023)와 직후 해(2024)만 사용해, 세 항이 들어간 회귀를 적합합니다.

```
data_usage ~ is_seoul + is_post + is_seoul:is_post
```

| 계수 | 의미 |
|---|---|
| `is_seoul` | 정책과 무관하게 서울·부산 사이에 원래 존재하던 평균 사용량 차이 |
| `is_post` | 두 도시 모두에 공통으로 작용한 시간 흐름에 따른 평균 변화 |
| `is_seoul:is_post` | 서울에서 2024년 이후에만 추가로 나타난 변화 = **정책의 순수한 효과 (DiD 추정치)** |

```
상호작용항(정책효과) 계수: +4.01 GB
참 효과: +4.0 GB
```

### 2-4. 상호작용항이 왜 정책효과인가 — 직접 계산으로 검증

DiD의 핵심 로직은 **뺄셈**입니다.

$$\text{DiD} = (A_2 - A_1) - (B_2 - B_1)$$

- $A_2 - A_1$ = 서울의 변화량 (시간 추세 + 정책 효과가 섞여 있음)
- $B_2 - B_1$ = 부산의 변화량 (시간 추세만 있음)
- 둘을 빼면 **공통 시간 추세는 상쇄**되고 **정책 효과만 남습니다.**

회귀식의 `is_seoul:is_post` 계수를 이 수식으로 직접 계산한 값과 비교하면 정확히 일치합니다.

### 2-5. 스스로 반증 시도 — 플라시보 검정

우리 추정치를 의심해봅니다. **정책이 없었던 구간**에 똑같은 DiD를 적용하면 효과가 0으로 나와야 정상입니다.

```
플라시보 검정 (2022 vs 2023, 둘 다 정책 이전)
상호작용항 계수: -0.003 GB
p-값: 0.9899

→ 유의하지 않음. 검정을 통과했습니다.
```

> 만약 여기서 유의한 효과가 나왔다면, **평행추세 가정 자체가 깨져 있거나** 서울·부산 사이에 정책과 무관한 다른 시기별 차이(예: 다른 정책, 경제 상황 변화)가 숨어있을 가능성을 의심해야 합니다.

---

## 3. PSM vs DiD — 언제 무엇을 쓰는가

| | PSM | DiD |
|---|---|---|
| 데이터 형태 | 한 시점의 단면 데이터 | 여러 시점의 패널 데이터 |
| 통제하는 교란요인 | 우리가 **관측하고 모형에 넣은** 것만 | 시간이 지나도 변하지 않는 특성이라면 **관측 못한 것까지** |
| 적합한 상황 | 배정에 영향을 준 교란요인을 우리가 이미 측정해둔 경우 | 특정 시점에 일부 집단에만 개입(정책 등)이 가해지는 경우 |
| 핵심 검증 절차 | 공변량 균형(Covariate Balance) | 평행추세 확인 + 플라시보 검정 |

---

## 4. 최종 보고 문장

**PSM:**
> 사전점수(pre_score)와 학습시간(study_hours)을 교란요인으로 선정하여 경향점수를 추정하고, 처치군과 대조군에서 경향점수가 비슷한 학생들끼리 짝을 지어 처치집단에 대한 평균 처치효과(ATT)를 계산했습니다. 그 결과 강의 수강의 효과는 약 5.02점으로 추정되었고, 공변량 균형 검증을 통해 짝짓기 후 두 집단 간 교란요인의 차이가 거의 사라졌음을 확인했습니다. 다만 사전점수와 학습시간 외에 관측하지 못한 다른 교란요인이 있다면 이를 반영하지 못한다는 한계가 있습니다.

**DiD:**
> 무료 공공 와이파이 정책을 시행하지 않은 부산(통제군)의 시간에 따른 변화량을 서울(실험군)의 변화량에서 빼는 이중차분법(DiD)으로 정책의 순수한 효과를 추정한 결과, 데이터 사용량이 약 4.01GB 증가한 것으로 나타났습니다. 이 방법을 쓰기 전에 정책 시행 이전 구간에서 서울과 부산의 데이터 사용량 격차가 일정하게 유지되는 평행추세 가정을 확인했고, 정책이 없었던 구간에 대한 플라시보 검정에서도 p-값이 유의수준보다 커 검정을 통과해 이 추정치의 신뢰성을 뒷받침했습니다.

---

## 5. 이 문제로 배운 것 (한 줄 정리)

> **실험할 수 없을 때도, 우리는 "가정을 명시하고 → 그 가정을 스스로 검증하는" 절차를 거치면 관찰 데이터만으로도 인과효과에 다가갈 수 있다.** 단, 그 추정치는 항상 "어떤 가정 위에서 얻어진 값인지"와 함께 보고되어야 한다.
